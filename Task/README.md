# Contacts App

Приложение представляет собой простое CRUD-решение для управления контактами с backend-частью на ASP.NET Core и базовым frontend-интерфейсом.

---

## Стек

- ASP.NET Core (.NET 9)
- Entity Framework Core
- PostgreSQL
- Docker, Docker Compose
- Bootstrap (frontend)
- Razor Views

---

## Архитектура и подход

Проект реализован с разделением ответственности:

- контроллеры отвечают за обработку HTTP-запросов;
- сервисный слой содержит бизнес-логику;
- доступ к данным инкапсулирован в DbContext (EF Core).

Используется Dependency Injection, асинхронные операции и централизованная обработка ошибок.

---

## Структура проекта

- **Task.Controllers** — API и MVC-контроллеры
- **Task.Services** — бизнес-логика и работа с данными
- **Task.DataBase** — DbContext и модели сущностей
- **docker-compose.yml** — запуск приложения и PostgreSQL
- **Dockerfile** — сборка backend-приложения

---

## Frontend

- Интерфейс реализован с использованием **Razor Views** и **Bootstrap**.
- Приложение предоставляет:
    - страницу со списком контактов;
    - формы создания и редактирования контактов;
    - удаление контакта с подтверждением.
- Поп ап меню с сохранением в БД без перезагрузки страницы.
- Frontend взаимодействует с backend через контроллеры ASP.NET Core.

---

## База данных

- Используется PostgreSQL.
- База данных создаётся автоматически при первом запуске приложения
  с помощью Entity Framework Core (`EnsureCreated`).
- Подключение к БД настраивается через переменные окружения.

---

## Инфраструктура

- Приложение и база данных запускаются в отдельных Docker-контейнерах.
- Docker Compose обеспечивает:
    - автоматический запуск PostgreSQL;
    - ожидание готовности базы данных перед стартом приложения;
    - проброс портов для локальной разработки.
